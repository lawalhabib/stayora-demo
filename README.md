# Stayora — short-let booking demo

Responsive luxury homepage starter using Next.js, React, TypeScript and custom CSS.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. In the terminal run `npm install`, then `npm run dev`.
4. Visit http://localhost:3000.

## Included
- Responsive luxury homepage
- Search form with date validation
- Three illustrative apartment cards
- Stayora branding and demo content

## Important
This is the frontend homepage only. Search currently validates dates and displays a demo message; it does not yet query a database or create bookings. Listings, prices, email and photos are illustrative. Next steps: property detail pages, PostgreSQL/Prisma, real availability and booking flow, admin dashboard, and Paystack test-mode integration.
